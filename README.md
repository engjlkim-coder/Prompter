# Mirror Screen (PWA)

PC 화면을 캡처해서 **좌우 반전**한 뒤, 다른 모니터(무선 HDMI 송신기가 연결된 모니터)에 전체화면으로 출력하는 PWA입니다.

```
[모니터1: 정상 화면] ── getDisplayMedia ──▶ [이 PWA 창 (모니터2 전체화면)] ──HDMI──▶ 무선 송신기 ▶ 수신기 ▶ 별도 모니터
                                              <video> + scale(-1, 1)
```

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 화면 및 컨트롤 UI |
| `style.css` | 스타일 (반전은 CSS `transform: scale(var(--fx), var(--fy))`) |
| `app.js` | 화면 캡처, 반전/맞춤 설정, 전체화면, 단축키, 설치 처리 |
| `manifest.json` | PWA 매니페스트 |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `icons/` | 앱 아이콘 (SVG, 192px, 512px) |

## GitHub Pages 배포

1. 새 저장소를 만들고 이 폴더의 파일을 **저장소 루트**에 올립니다.
   ```bash
   git init
   git add .
   git commit -m "Add Mirror Screen PWA"
   git branch -M main
   git remote add origin https://github.com/<계정>/<저장소>.git
   git push -u origin main
   ```
2. GitHub 저장소 → **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` → Save
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 로 접속됩니다. (HTTPS라 화면 캡처/PWA 설치가 모두 동작)

모든 경로는 상대경로라 `/<저장소>/` 하위 경로에서도 그대로 동작합니다.

## 사용 방법

1. Windows **설정 → 디스플레이 → 여러 디스플레이 → "이 디스플레이 확장"** (복제 ✕)
2. Chrome 또는 Edge로 접속 후 주소창 오른쪽 **설치(앱 설치)** 아이콘으로 PWA 설치 (선택)
3. 앱 창을 **모니터2**(무선 HDMI로 나가는 화면)로 옮김
4. **캡처 시작** → 공유 팝업에서 **모니터1 "전체 화면"** 선택
5. **모니터2 전체화면** 버튼 (첫 사용 시 "창 관리" 권한 허용) — 안 되면 창을 모니터2에 둔 채 **현재 화면 전체화면**

## 단축키

| 키 | 동작 |
|---|---|
| `C` / `X` | 캡처 시작 / 중지 |
| `H` / `V` | 좌우 / 상하 반전 토글 |
| `F` | 현재 화면 전체화면 토글 (더블클릭도 동일) |
| `M` | 모니터2 전체화면 |
| `O` | 화면 맞춤 변경 (비율 유지 → 꽉 채움 → 늘림) |
| `T` | 컨트롤 패널 표시/숨김 |

송출 중에는 마우스를 3초간 움직이지 않으면 패널과 커서가 자동으로 숨겨집니다. 단축키는 **이 창에 포커스가 있을 때만** 동작합니다. 모니터1에서 작업하는 동안에는 반전 토글이 필요하면 창을 한 번 클릭하세요.

## 알아둘 점

- **캡처 대상은 반드시 모니터1.** 모니터2(이 창이 있는 화면)를 고르면 자기 자신이 반복 출력됩니다.
- 공유 선택 팝업은 **캡처를 시작할 때마다** 표시됩니다 (브라우저 보안 정책, 자동 시작 불가).
- Netflix 등 **DRM 콘텐츠는 검은 화면**으로 캡처됩니다.
- 마우스 커서도 반전되어 보이지만, 실제 커서는 모니터1에서만 움직입니다.
- 전체화면 + 송출 중에는 화면 꺼짐 방지(Wake Lock)가 켜집니다.
- 코드를 수정해 재배포할 때는 `sw.js`의 `CACHE` 버전(`mirror-pwa-v1`)을 올려야 설치된 앱에 반영됩니다.
- 지원 브라우저: 데스크톱 Chrome / Edge (Window Management API 사용). Firefox/Safari는 캡처는 되지만 "모니터2 전체화면" 버튼은 동작하지 않습니다.
